## Notas para o Claude Code

- Responda ao usuário em português (pt-BR), salvo se ele escrever em outro idioma.
- Antes de concluir uma alteração de código, rode `npm run build`. Não há suíte de testes.
- Para mudanças de interface, verifique no navegador com `npm run dev` + `node server.js` ativos, em largura de desktop e de celular.
- `data/data.json` contém dados reais. Leia-o quando precisar entender o formato, mas não o modifique para testes.
